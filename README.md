# Ultra-High-Energy Cosmic Rays (UHECRs)

This repository contains the analysis code, simulation scripts, and supporting files used for my undergraduate research project investigating ultra-high-energy cosmic-ray composition using CORSIKA.

## Repository Contents

- Data analysis code
- Simulation scripts
- CORSIKA steering files
